# GDENG03-Basic Scene Editor
This was a major project that I developed to create my own scene editor using C++ and DirectX on Visual Studio. It contains multiple systems of rendering, camera, physics, entity-component, and scene saving/loading. Other libraries that I used are ImGUI, RealPhysics3D, and nlohmann JSON.

### Note:
